# Projeto Integrador 2 - 

## Definições do Plano de ação

| **Disciplina** | *Projeto Integrador em Computação II* |
| --- | --- |
| **Tema escolhido pelo grupo com base no tema norteador da Univesp** | *Desenvolver um software com framework web que utilize banco de dados, inclua script web (Javascript), nuvem, uso de API, acessibilidade, controle de versão e testes. Opcionalmente incluir análises de dados.* |
| **Título provisório do trabalho** | *IceWebCream 2.0: Plataforma Web em nuvem para Gestão de Estoque e integração com fornecedores* |
| **Problema** | *O protótipo desenvolvido na disciplina Projeto Integrador I, focado em resolver o problemas de procedimentos manuais de estoque, possui limitações de arquitetura por operar apenas localmente e de forma síncrona, gerando uma operação semi-automatizada por carecer de acesso remoto em tempo real e integração direta com fornecedores.* |
| **Objetivo** | *Evoluir o protótipo para uma aplicação web hospedada em nuvem com banco de dados em produção, interatividade assíncrona via JavaScript, consumo de APIs externas para comunicação com fornecedores, recursos de acessibilidade web e rotinas de testes automatizados.* |
